# PhotoBot – Automated Smart Photography Robot

## Project Overview

PhotoBot is a smart self-service photography system designed to automate the process of capturing photographs without requiring a photographer.

The system is designed to assist users with positioning, framing, and automated photo capture using computer vision and a servo-controlled camera mechanism.

This project was developed as an academic team project and was also documented through a research publication.

## Key Features

- Automated photo capturing
- Face detection for user positioning
- Automatic framing and camera positioning
- Servo-controlled camera mechanism
- Multiple photo capture
- Computer vision-based image processing
- Self-service photography workflow

## Technologies Used

- Python
- OpenCV
- Computer Vision
- Servo Control
